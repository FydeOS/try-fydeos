Try FydeOS runs FydeOS on a Mac or a Windows PC without installing it. It is a small launcher that wraps QEMU and the host's own hypervisor around the stock FydeOS VMware image, the same image FydeOS publishes for VMware. Nothing to configure: open the app, it downloads the image on first launch, converts it and boots FydeOS in a window. This is the first public release.

## What it does

- Downloads the official FydeOS v23.1 image for your machine on first launch (about 1.5 GB on Apple Silicon, 1.8 GB on Windows), verifies it and keeps it for factory resets.
- Boots it with the host hypervisor, Hypervisor.framework on Apple Silicon and the Windows Hypervisor Platform on Windows, with accelerated graphics through VirGL.
- A start menu sets cores, memory, full screen and microphone, shows the last run's status and offers a factory reset. After Launch, FydeOS owns the window.
- Shares the clipboard with the host, text in both directions.
- Keeps your FydeOS data on the host between runs, in a sparse disk that grows up to 64 GiB as you use it.

## Requirements

- macOS 15 or later on Apple Silicon.
- Windows 10 or 11 on x86-64 with the Windows Hypervisor Platform feature enabled.

## Downloads

- `TryFydeOS-0.4.0.dmg` for macOS.
- `TryFydeOS-0.4.0.exe` for Windows, a single self-contained file.

The installers are not code-signed yet. On macOS, Gatekeeper blocks the first open; allow it under System Settings > Privacy & Security > Open Anyway, then open it again. On Windows, SmartScreen shows a warning; choose More info, then Run anyway.

## Known limitations

- Clipboard sharing is text only.
- No Linux version yet.

## About

Modeled on [Try Omarchy](https://tryomarchy.com) (MIT). The QEMU runtimes are built from Try Omarchy's recipes, pinned by commit and hash, with this project's patches; the launchers, storage and guest contract are this project's own. Source, issues and the build pipeline: https://github.com/FydeOS/try-fydeos. Built and published by GitHub Actions from the `v0.4.0` tag.
